# Phase 3 — Output pathway audit

Status: shipped v0.1.0
Date: 2026-05-11

This artwork's outputs are sensory (visuals + audio playing live on the viewer's phone), not
data. The audit lists each output and notes which "export" categories from the catalog do not
apply.

| Output pathway                                   | Status             | Notes                                                                                                                                    |
| ------------------------------------------------ | ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| On-canvas visual overlay tracking the marker     | ✅ green           | `src/ui/overlay.ts`. Hue / intensity / particle count / pulse rate respond to `AttentionState` + `PoseSummary`.                          |
| Ambient drone audio                              | ✅ green           | `src/primitives/audio.ts`. Carrier, modulator, amplitude, noise respond to `AudioState`.                                                 |
| Debug overlay (markers, attention, hue, samples) | ✅ green           | Toggle in menu, rendered onto `debug-canvas`.                                                                                            |
| Printable sculpture tags page                    | ✅ green           | `docs/tags/printable.html`, generated at build time from `js-aruco2` via `scripts/generate-tags.mjs`. 8 markers (ids 0–7).               |
| Privacy statement (`/privacy.html`)              | ✅ green           | Linked from the About section of the menu.                                                                                               |
| Build metadata (version / commit / built-at)     | ✅ green           | `docs/version.json`, also injected into the menu's About section by `bindAboutMetadata` in `src/app.ts`.                                 |
| State export / share-link / "save my session"    | ⚪ out of scope    | The artwork's state is ephemeral and meaningless outside the live moment in front of the sculpture. Documented in README "Out of scope". |
| CSV / JSON / API export                          | ⚪ out of scope    | No exportable data product.                                                                                                              |
| Print / PDF view                                 | ⚠ partial          | `docs/tags/printable.html` is print-styled (`@media print`). The artwork itself is not a printable view.                                 |
| Screenshot                                       | ⚪ delegated to OS | Phones can take screenshots. We do not add a custom screenshot UI.                                                                       |
| Embed code                                       | ⚪ out of scope    | The artwork is the page; embedding a camera-permission experience in an iframe is hostile UX.                                            |

## Verification

- Visual / audio reactions were exercised by enabling the simulated demo and observing the
  status pill, debug overlay numbers, and audio output.
- The printable tags page was generated by `node scripts/generate-tags.mjs` and verified to
  render 8 markers.
- `docs/version.json` is produced by `scripts/write-version.mjs` and checked by
  `scripts/check-pages-build.mjs` on every build.
